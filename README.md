# arnauddeturckheim.com

Site statique d'une page autour de l'exposition *Ce Qui Demeure* (novembre 2026).

- `build.py` génère `index.html` (contenu repris du preview, sans les prix).
- `content/texte.txt` : texte de Pierre El Khoury (copie de `Expo/8 - Texte exposition/texte.txt` sur le Drive).
- `img/` : photos redimensionnées depuis `Expo/1 - Photos/3 - JPEG` (2200 px et 900 px).
- `CNAME` : domaine personnalisé pour GitHub Pages.

Mettre à jour : modifier `build.py` ou `content/texte.txt`, lancer `python3 build.py`, committer, pousser.
